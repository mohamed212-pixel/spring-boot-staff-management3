## How to Run
```bash
./mvnw spring-boot:run
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/staffs` | Get all staff |
| GET | `/staffs/{id}` | Get staff by ID |
| POST | `/staffs` | Create staff |
| PUT | `/staffs/{id}` | Update staff |
| DELETE | `/staffs/{id}` | Delete staff |
